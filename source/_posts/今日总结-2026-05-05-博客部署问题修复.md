# 今日总结：2026-05-05

## 完成项

### 1. 博客部署问题修复

**问题诊断：**
1. `package.json` 缺少 `hexo` 字段，导致 hexo-cli 无法正确识别项目
2. `_config.yml` 中 `message: Site updated: YYYY-MM-DD HH:mm:ss` 缺少引号，YAML 解析失败
3. 缺少 `hexo-renderer-marked` 渲染器，markdown 文件无法生成 HTML
4. `.deploy_git` 子模块损坏

**解决方案：**
```bash
# 1. package.json 添加 hexo 字段
"hexo": {
  "version": "8.1.1"
}

# 2. _config.yml 修复 message 引号
message: "Site updated: YYYY-MM-DD HH:mm:ss"

# 3. 安装渲染器
npm install hexo-renderer-marked --save

# 4. 删除损坏的部署目录后重新部署
rm -rf .deploy_git
hexo deploy
```

**根因分析：**
- 之前一直通过 `node -e "require('./node_modules/hexo-cli/dist/hexo.js')()"` 手动调用能部分工作，是因为直接加载了 CLI 模块，但 find_pkg 找不到 hexo 字段导致无法加载正确的 hexo 实例
- 渲染器缺失导致 posts 被 processed 但没有生成 HTML 文件
