抖音AI创变者大赛参赛手记：听见入境

记录日期：2026年5月20日
赛道：赛道四 - 视觉搜索
团队：3人

项目灵感

参加抖音AI创变者大赛，我们选择了赛道四：视觉搜索。一开始想做”视频BGM识别”，但觉得太简单。后来升级成：

“听见即入境” —— 识别BGM → 分析情绪/场景 → 推荐同氛围视频/滤镜/拍摄脚本 → 语音生成拍摄建议

这个方向结合了音频识别、多模态理解、推荐系统，既有技术挑战，又有实用价值。

技术方案

技术栈

  • 前端：React + TypeScript + Vite（纯前端H5）
  • 音频识别：AudD API（免费100次/天）
  • 情绪分析：豆包/kimi LLM API（可选）
  • 部署：本地运行 → 内网穿透 → 二维码接入抖音虚拟平台

核心流程

设计风格

我们选择了人文温馨风格，区别于常见的霓虹赛博朋克：

  • 暖米色背景（#F7F5F0）—— 温和不刺眼
  • 赭红色强调（#C67B5A）—— 温暖的品牌色
  • Noto Serif + Noto Sans —— 中文衬线字体，叙事感
  • 柔和阴影 —— 轻盈的卡片投影
  • 响应式设计 —— 移动端 + 桌面端双适配

项目结构

遇到的问题与解决

1. 音频识别 API 选择

一开始想用 ACRCloud，但注册流程太复杂。后来发现 AudD 更简单：

  • 注册只需邮箱
  • 免费100次/天，够比赛用
  • API 接口简洁

2. 设计风格

最初做了霓虹赛博朋克风格，但觉得太”AI味”，不够温暖。后来改成了人文温馨风格，用暖米色 + 赭红，配合柔和的动效，视觉上更舒适。

3. 响应式适配

需要同时适配手机和电脑。最终方案：

  • < 380px：紧凑移动端
  • ≥ 720px：桌面端（更大留白）
  • ≥ 1024px：大屏横屏

下一步

  • 内网穿透 + 二维码
  • LLM API 接入（可选）
