十、一次成功发布的判断标准

一次完整发布应该满足：

  1. npm.cmd run build 成功。
  2. npm.cmd run deploy 成功。
  3. GitHub Pages 首页能看到新文章。
  4. Markdown 源文件已经提交到 source 分支。
  5. 没有把 debug.log、themes/ 等无关文件一起提交。

这样既能保证线上博客更新，也能保证文章源码可追溯。
